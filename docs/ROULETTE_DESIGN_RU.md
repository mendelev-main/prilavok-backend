## Причина и решение

Четырёхцветный conic-gradient повторял красные оттенки. На замыкании списка и при нечётном количестве товаров они могли сливаться. Новый SVG рисует каждую кольцевую секцию отдельным path с явно заданными границами. Неактивные сектора графитовые, один текущий сектор коралловый, с контрастной окантовкой. Это не зависит от чётности числа товаров.

Палитра сайта сохранена: фон #08090b, окно #111318, контролы #1a1d22, сектора #272b32/#343943, текст #f5f5f2, акцент #ef765e. Типографика наследуется от сайта. Колесо содержит только номера; центральная втулка показывает текущий номер; название и цена вынесены в отдельный блок под колесом. Длинные названия переносятся. Указатель, обод, границы, выбранный сектор и состояния кнопок имеют отдельные роли. В маленьком окне кнопки складываются вертикально, само окно прокручивается.

## Сохранённое поведение

Одна RAF-анимация управляет вращением, текущим сектором и названием. Случайная длительность 4–8с сохранена. Конечный сектор математически соответствует выбранному товару. Закрытие отменяет RAF; смена категории запрещена во время движения; доступность результата повторно проверяется. Reduced motion не запускает длительную анимацию. aria-live только финальный результат, focus-visible на контролах, фокус при старте перемещается на доступную кнопку закрытия.

Разметка обеих страниц подключает согласованные JS/CSS URL roulette-20261010-3. Изменения не затрагивают оформление заказа, stock authority или Telegram. Существующая cart dock CSS сохранена.
