# Синхронная рулетка — 10.10.2026

Обе кнопки: «Не можете выбрать?» и подпись «Крути рулетку». Модальное окно: «Рулетка», «Выберите категорию — мы предложим случайный доступный товар.» Убрана дополнительная надпись «Помощь с выбором».

До изменения CSS вращала круг на 1080°, JS независимо менял имя каждые 130ms и выбирал результат по завершении 2600ms; положение круга не соответствовало названию/результату. Теперь один requestAnimationFrame timeline задаёт угол и имя сектора под указателем. Результат случайно выбирается до вращения; wheel совершает минимум пять оборотов и замедляется точно к центру выбранного сектора за случайные 4000–8000ms. Количество секторов равно количеству доступных товаров категории. Номера на ободе и центральный номер связывают положение и название; в больших категориях часть меток пропускается для читаемости, товары не исключаются из выбора.

Категория заблокирована во время вращения. Закрытие отменяет RAF и инвалидирует callback. Перед показом/открытием результата повторно проверяется доступность. Reduced motion сразу показывает тот же корректно расположенный результат. Нет озвучки всех промежуточных имён screenreader; финальный результат aria-live polite. Добавлены focus-visible и focus trap; body overflow восстанавливается. Существующий стиль сайта сохранён.

Регрессии: попадание указателя на выбранный сектор при разных размерах категорий и повторных вращениях; монотонное замедление единого timeline; тексты и отсутствие раздельных таймеров. Локально только syntax/diff, CI pending до подтверждения. Физическая приёмка: выбранное имя/номер соответствует указателю, повторное вращение и закрытие во время движения, один товар, пустая категория, reduced motion, исчезновение товара во время вращения. Проверка на телефоне/планшете pending.

Повторная правка: JS/CSS version query roulette-20261010-2 на обеих страницах. Это устраняет повторное использование старого URL ресурса после обновления HTML. Kicker отсутствует в JS и скрыт в CSS на случай промежуточного смешивания версий. Текущий сектор/название обновляются одним RAF; доступные метки активного сектора выделяются. Старые CSS animation/transition для wheel запрещены. Длительность выбирается crypto random отдельно от результата. CI/deployment pending до проверки.
