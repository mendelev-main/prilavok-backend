# Мерцание фотографий при загрузке сайта

Причина: localStorage меню быстро показывается, затем availability/catalog fetch вызывает полную замену grid.innerHTML. Все img nodes уничтожаются, создаются новые, заново запускается анимация карточек. Browser cache может избежать скачивания, но не устраняет замену DOM и анимацию. Backend boot revision меняется при рестарте, поэтому один лишь revision не доказывает изменение визуального каталога.

Обе поверхности /menu и /: сравнение визуального каталога исключает stock и transport revision. При одинаковых товарах и категориях существующие img nodes сохраняются. Остатки обновляются адресно: sold-out классы, overlay, надпись, add/quantity buttons. Корзина сверяется с новыми остатками, detail control обновляется. Реальные изменения названий/цен/фото/категорий по-прежнему перестраивают каталог. Начальная отрисовка и намеренное переключение категории сохраняют исходное оформление. Проверка каталога/остатков не удалена.

Меню открывает актуальный объект товара при клике, чтобы прежний event closure не показывал старые остатки. При отсутствии каталога запрашивается полное меню даже при пустом revision. Shared script guest-catalog-view.js загружается до inline runtime.

Добавлены три регрессии: сравнение revision/stock и реальных изменений, отсутствие повторного render на обеих поверхностях, сохранение image identity при stock toggle. Существующий VM fixture загружает новую зависимость. Локально только node --check и git diff --check; тесты и сборка выполняются в CI. CI/deployment pending до подтверждения.

Приёмка: открыть страницу, обновить при наличии кеша — фото не мигают повторно после ответа сети. Проверить sold-out↔available, уменьшение остатка ниже cart qty, restart backend с тем же каталогом и реальное изменение фото/цены. Не утверждается отсутствие первой загрузки изображения или любой анимации при намеренном переключении категории.
