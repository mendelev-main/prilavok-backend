# better-web-ui Project Context

## Design Context

### Users
Prilavok is a small-town café ecosystem. Guest-facing surfaces are used primarily on phones to browse the menu and place orders quickly. Staff-facing and print surfaces are operational tools used by the café team. Print Menu Studio produces attractive, practical menus that can be sent directly to print.

### Brand Personality
Warm, contemporary, human. Distinctive without feeling luxury-for-luxury's-sake. The visual identity should feel like an independent café with taste, not a generic SaaS product or an AI-generated template.

### Aesthetic Direction
Use strong editorial hierarchy, deliberate typography, modular composition, controlled asymmetry, warm/tinted neutrals, and restrained but confident accent colors. Designs may be modern, editorial, playful, or poster-like when appropriate, but each proposed direction must be structurally distinct rather than the same grid with different colors. Avoid generic card grids, excessive glassmorphism, neon/cyan-on-dark AI aesthetics, arbitrary gradients, decorative effects without purpose, and monotonous equal spacing.

For Print Menu Studio specifically, prioritize print readability and real graphic-design composition. The large menu masthead belongs only on the first page. Later pages should maximize usable menu content. Menu concepts should differ in information architecture, grid, typographic voice, density, and category treatment—not merely palette.

### Implementation Defaults
Existing stack is authoritative: Node.js + Express 5 backend, plain HTML/CSS/JavaScript frontend, Supabase data source. Preserve vanilla frontend implementation unless a change is explicitly justified. Public menu data comes from /api/menu. Print surfaces target A4 first and must remain browser-print friendly.

### Design Principles
1. Establish hierarchy and composition before color or decoration.
2. Make each concept structurally distinct: change grid, rhythm, type hierarchy, density, and grouping—not just theme.
3. Use typography as a primary design material; avoid default/system-looking typography when the surface is brand-forward.
4. Prefer modular rhythm and intentional asymmetry over repetitive equal cards or identical section treatments.
5. Keep guest and print experiences immediately understandable: expressive design must never reduce menu readability, price scanning, or print reliability.
